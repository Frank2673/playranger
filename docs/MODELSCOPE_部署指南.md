# 魔搭社区（ModelScope）部署指南

> 目标：让中国境内用户通过浏览器公开访问 PlayRanger 控制台，注册后即可试用。
>
> 适用版本：v0.3.0+ · 部署形态：**Docker 创空间**（Gradio/Streamlit 形态不适合本项目：
> 需要后台任务队列 + 浏览器 + 持久化）

---

## 1. 为什么选 Docker 形态

| 形态 | 是否适用 | 原因 |
|------|----------|------|
| Static | ❌ | 只有前端，没有任务调度与浏览器 |
| Gradio | ❌ | 交互模型是「一问一答」，无法承载长任务队列 |
| Streamlit | ❌ | 同上，且不支持后台 worker |
| **Docker** | ✅ | 可跑 FastAPI + Playwright + SQLite，端口 7860 |

魔搭 Docker 硬性约束（踩坑点）：

1. **必须监听 `0.0.0.0:7860`**，用 8080 会部署失败
2. **不要依赖 `Authorization` 请求头**（平台会拦截），本项目用 Cookie 会话
3. 镜像内不要写入平台保留的 `X-ModelScope-*` 头
4. 容器磁盘**不保证持久**，重要产物要外挂或转存

## 2. 三步部署

### 第 1 步：Fork 仓库

打开 <https://github.com/Frank2673/playranger> → Fork 到你自己的账号。

也可以不 Fork，直接在魔搭用「关联 GitHub 仓库」的方式拉取。

### 第 2 步：创建 Docker 创空间

1. 登录 <https://modelscope.cn>
2. 「创空间」→「创建创空间」
3. 填写：
   - 空间名称：`playranger`
   - 许可证：MIT
   - **SDK 类型：Docker**
   - 可见性：公开
4. 创建后进入「设置」→ 绑定你的 GitHub 仓库（或直接用魔搭 Git 推送）

### 第 3 步：配置环境变量

在创空间「设置 → 环境变量」中填入（**不要写进代码或仓库**）：

| 变量 | 必填 | 说明 |
|------|------|------|
| `LLM_API_BASE` | ✅ | 如 `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | ✅ | 你的 Key（只存在平台环境变量里） |
| `LLM_MODEL` | ✅ | 如 `deepseek-chat` |
| `VLM_API_BASE` | 可选 | 不填则复用 LLM 配置 |
| `VLM_API_KEY` | 可选 | 同上 |
| `VLM_MODEL` | 可选 | 视觉模型，如 `qwen-vl-max` |
| `PLAYRANGER_WORKSPACE_ROOTS` | 可选 | 允许多用户上传源码的目录白名单 |

保存后平台会自动重新构建并启动。

## 3. 首次启动必做（安全）

1. 打开空间首页 → 进入控制台
2. **立刻注册第一个账号** —— 本项目设计为「首位注册用户自动成为管理员」
3. 确认管理员账号已生效，然后关闭公开注册（如需邀请制）

> 密码存储：Argon2id（内存 19 MiB / 迭代 2 / 并行 1），数据库中只有哈希。
> **包括管理员在内，任何人都无法读取用户的明文密码**。
> 管理员只能「重置密码」，不能「查看密码」。

如果忘记管理员密码，只有两条路：

- 在容器内用 CLI 重置（需要空间写权限）
- 删除 `output/platform.db` 重新初始化（会清空所有账号与任务）

## 4. 资源建议

| 场景 | 规格 | 说明 |
|------|------|------|
| 只看界面/试跑 | 2 核 4 GB | 单任务、轻量网页游戏 |
| 正常试用 | 4 核 8 GB | Chromium + 1~2 并发 |
| 多用户 | 8 核 16 GB | 建议加外部队列与对象存储 |

浏览器在容器内以 headless 运行；**不要**试图在魔搭容器里跑 Android/iOS 适配器
（没有 USB 设备与 macOS 宿主）。多端适配请用本地部署。

## 5. 部署后验证清单

按顺序执行，全部通过才算部署成功：

```bash
# 1. 健康检查（HTTP 200）
curl -I https://<你的空间地址>.modelscope.space/

# 2. 控制台可打开
#    浏览器访问 → 应看到注册/登录页

# 3. 注册首个账号 → 自动成为管理员

# 4. 新建一个测试任务
#    URL 填: https://play2048.co  （或你自己的游戏地址）
#    步数: 10

# 5. 任务详情能看到
#    - 逐步动作轨迹
#    - 每步截图
#    - 最终报告
```

失败排查：

| 现象 | 原因 | 处理 |
|------|------|------|
| 部署后 502 | 端口不是 7860 | 检查 `Dockerfile` 的 `EXPOSE` 与 `--port` |
| 页面能开但任务一直 pending | 没有 worker / 内存不足 | 升配到 4 核 8 GB |
| 任务报浏览器启动失败 | 镜像里没有 Chromium | 基础镜像必须是 `mcr.microsoft.com/playwright/python` |
| 截图全黑 | 容器缺 GPU/字体 | 已装 `fonts-noto-cjk`；无 GPU 时用软件渲染 |
| 登录后立刻掉线 | Cookie 被反代剥离 | 确认反向代理允许 `Set-Cookie` |

## 6. 与 GitHub 的关系

- **源码与 Issue**：GitHub（<https://github.com/Frank2673/playranger>）
- **在线试用**：魔搭创空间
- **下载**：GitHub Releases 里提供 wheel / sdist；也可 `pip install git+https://github.com/Frank2673/playranger.git`

两边内容一致：魔搭只是把同一个 Dockerfile 跑起来，不维护第二套代码。

## 7. 合规提醒

- 只测试**你有权测试**的游戏；不要用本平台扫描他人线上服务
- 不要把用户的游戏源码/截图用于训练或对外分享
- 公开空间建议加访问频率限制，避免被当作免费代理
- 若收集手机号/邮箱，需在页面提供隐私政策与删除入口（《个人信息保护法》要求）
